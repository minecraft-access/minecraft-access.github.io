# Downloads

Minecraft Access is available for Fabric or Neoforge on Windows, Linux and Mac.

See the [Fabric setup guide](https://docs.mcaccess.org/setup/basic) (recommended) or the [Neoforge setup guide](https://docs.mcaccess.org/setup/advanced).

Minecraft Access is also a part of some unofficial [community-made modpacks](https://docs.mcaccess.org/good-resources/#community-modpacks).
